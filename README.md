# BreachShield — موقع فحص تسريبات البريد

موقع عربي/إنجليزي بواجهة متجاوبة، يستخدم واجهة XposedOrNot المجانية لفحص ظهور البريد في التسريبات المعروفة.

## الملفات
- `index.html`: الموقع كاملًا (HTML وCSS وJavaScript) ولا يحتاج مكتبات خارجية.

## تشغيله محليًا
افتح `index.html` في المتصفح، أو شغّله عبر خادم محلي بسيط. اتصال الإنترنت مطلوب لميزة الفحص.

## نشره مجانًا على GitHub Pages
1. أنشئ مستودع GitHub جديدًا.
2. ارفع ملف `index.html` إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر النشر من الفرع `main` والمجلد `/ (root)`، ثم احفظ.
5. انتظر ظهور رابط الموقع.

## كيف يعمل الفحص؟
يُرسل الموقع عنوان البريد إلى:
`https://api.xposedornot.com/v1/check-email/{email}`
وتعيد الخدمة أسماء حوادث التسريب المتاحة لديها عند العثور عليها. الخدمة المجانية لها حدود استخدام، وقد يتوقف الفحص مؤقتًا عند تجاوزها.

## حدود مهمة
- هذا فحص للتسريبات المعروفة في قاعدة بيانات خارجية فقط، وليس فحصًا شاملًا لكل الإنترنت.
- لا يمكن معرفة جميع المنصات المرتبطة ببريد إلكتروني بشكل موثوق من مصدر عام واحد.
- عدم العثور على نتائج لا يعني أن الحساب آمن 100%.
- لا تطلب من المستخدمين كلمات المرور أو رموز التحقق.
- عنوان البريد يُرسل إلى مزود الفحص الخارجي عند الضغط على زر الفحص. اذكر ذلك بوضوح في سياسة الخصوصية قبل نشر الموقع على نطاق واسع.
- راجع شروط خدمة مزود البيانات وحدود الاستخدام قبل استخدام الموقع تجاريًا أو مع عدد كبير من الزوار.


## مستشار الأمان
بعد الفحص تظهر أسئلة إرشادية محددة وإجابات تتغير حسب نتيجة الفحص. هذه النسخة تستخدم قواعد واضحة وإجابات معدّة مسبقًا، وليست نموذج ذكاء اصطناعي توليديًا. لإضافة ذكاء اصطناعي حقيقي لاحقًا، يجب ربط نموذج عبر خدمة خلفية (backend) وعدم وضع مفتاح API داخل `index.html` حتى لا ينكشف للزوار.
